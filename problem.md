# Problem

Working in a salon setting can be nerve-wracking, especially for a first time nail technician. This salon setting may not be for every nail tech, and a student may want to see if this is the right place for them or if they are better suited being self-employed. But currently there is no way to experience the salon firsthand until one has already begun working there.

# Initial requirements

- R1: The program must handle client walk-ins that show up randomly and those who do have an appointment at set times.
- R2: The program must ask the client if there are any special health conditions that should be taken into consideration before starting the service.
- R3: The program must ask the client to wash their hands prior to starting any hand services; not needed for pedicures. (changed in round 3)
- R4: Each service must require filing, buffing, and polishing. If the client already has product on their nails, they will need to begin with product removal first.
- R5: The client should rate the service with whether they are satisfied or not by giving the player a star at the end of the service. This will determine if money was made from the service. Doing the steps in the wrong order will make the client unsatisfied.
- R6: At the end of the work day, the program must display the total earnings for the day, and determine if the daily goal was met. 

# Round 2 requirements

- R7: The game must be playable in a browser on my own computer, started with one command.
- R8: The game must be animated. It should be from the nail technician's point of view and should display the filing, buffing, polishing, etc. Each step the player picks will have its own animation. The nails must change as the player goes; they look polished after the polish step. Introduce lots of color throughout the animation.

# Round 3 requirements
- R9: The game must display the rules at the beginning before choosing to begin.
- R3 changes: When the client selects the pedicure service, the game must show a washing animation similar to the handwashing, but for pedicures.

# Round 4 requirements

- R10: The game must include a new part of the service which includes nipping the cuticles. It must come after filing the nails, and right before buffing.
- R11: If the client responds with a diabetic medical condition, nipping cuticles must be excluded from the service requirements.
